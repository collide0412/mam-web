# AGENTS

This repository is the Măm GitHub Pages PWA.

## Working rules
- Keep the app static, local-first, and installable as a PWA.
- Prefer mobile-first design and accessible native web patterns.
- Use IndexedDB for user data and bundled static data for the offline catalog.
- Keep the app deployable under a GitHub Pages subpath with correct Vite base config.
- Update RUN_STATE.md as the required resume point whenever the work is interrupted.
