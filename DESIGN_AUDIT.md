# Design audit

## Direction
The product should feel warm, modern, calm, and food-focused; the interface should prioritize a mobile-first calorie tracker experience with strong call-to-action hierarchy.

## Current gaps
- Default Vite starter still needs replacement with product-specific design system and navigation.
- Need a single source of truth for typography, spacing, controls, and surfaces.
- Need Today screen hero, add-food flow, diary, recommendations, and profile screens aligned to Măm’s product intent.

## Next implementation priorities
1. Replace default app shell with a mobile-first information architecture.
2. Define central design tokens and shared primitives.
3. Implement the primary Today flow centered on calorie progress and action CTA.
4. Add the offline food search and detail view.
5. Add PWA and GitHub Pages deployment readiness.
