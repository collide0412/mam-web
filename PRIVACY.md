# Privacy and local data

Măm is designed as a static offline-first application. Personal meal history, profile data, and settings are stored locally in the browser using IndexedDB.

- GitHub Pages hosts the static frontend only.
- There is no application backend in this MVP.
- Food data ships with the application bundle so it works offline.
- Clearing browser site data may remove local profile and meal history.
- No personal data is sent to a remote analytics service.
